# DES-Population-Dynamics
DES-Population-Dynamics es un simulador de Eventos Discretos (DES) que proyecta la dinámica demográfica de una región por 100 años. Utiliza un motor estocástico para modelar nacimientos, muertes, parejas y duelos mediante probabilidades y distribuciones manuales. Ideal para analizar la evolución poblacional con rigor técnico.
